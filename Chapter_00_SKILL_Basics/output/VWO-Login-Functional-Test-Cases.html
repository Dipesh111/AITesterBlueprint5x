Execution assumptions
  • Test accounts, identities, SSO providers, 2FA devices, reset tokens, and environment URLs must be provisioned by the project team.

  • Session timeout, reset-token lifetime, rate-limit thresholds, and the exact SSO provider list require confirmation.
